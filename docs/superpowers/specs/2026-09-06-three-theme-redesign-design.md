# 重设计规格：三主题可切换 UI（暗夜玻璃 / 纯净亮色 / 经典白玻璃）

日期：2026-09-06
状态：已获用户批准的设计（待实现）
范围：纯视觉层重做。`money.py`、config 其余字段、窗口缩放机制、tick 循环、下班询问逻辑全部不动。

## 1. 背景与目标

现有 UI 的问题（审计结论）：

1. 大金额用雅黑比例字体，每秒跳动时宽度抖动；
2. 全部文字靠 8 向白描边光晕保可读，文字发虚、观感廉价；
3. 玻璃面板模糊不足（blur 5 / 白叠加 12%），壁纸主体透过面板干扰数字；
4. 顶部/底部黑色渐变 scrim 有色带；
5. 主数字字号上限 56px 偏小；mint 强调色压在暖色壁纸上对比度弱；
6. 原生菜单/弹窗风格与"苹果玻璃"承诺脱节。

目标：按已批准的三个视觉方向重构材质层，并做成可切换主题；主数字改等宽字体；
强调色锁定冰蓝；删除描边光晕 hack；弹窗/菜单跟随主题。

## 2. 主题系统

### 2.1 主题定义（`app.py` THEMES 重构）

| key | 名称 | 材质 | 强调色（主数字/状态行/主按钮） |
|---|---|---|---|
| `midnight` | 暗夜玻璃 | 壁纸压暗 50% + 渐晕 + 暗玻璃面板 | `#7DB8FF` |
| `paper` | 纯净亮色 | 壁纸 blur 26 + 白化 78%，近实白卡片 | `#0A84FF` |
| `glass` | 经典白玻璃 | 壁纸原样 + 白玻璃 46% | `#0066D6` |

- 默认主题：`midnight`。
- 强调色锁定为冰蓝系，每个主题一个固定值（见上表）；旧 `mint/amber/sky` 菜单移除。
- exploit（加班压榨）不依赖主题选择：任何主题下加班统一为暗红风格（见 §4）。

### 2.2 迁移与兼容（`load_config`）

- 旧值 `mint/amber/sky` → 自动迁移为 `glass`（观感延续）；
- 未知/非法值 → 回退 `midnight`；
- 其余 config 字段与校验逻辑不变。

### 2.3 菜单

- 顶部「主题」菜单 = 三个 radiobutton：暗夜玻璃 / 纯净亮色 / 经典白玻璃；
- 切换主题：立即重烘焙背景 + 重绘 + 持久化到 config.json（沿袭现有 `_on_theme_change` 流程）；
- 菜单栏配色跟随主题：midnight = 深底白字蓝高亮；paper/glass = 浅灰底墨字蓝高亮（现状）。

## 3. 背景烘焙（make_bg.py）

### 3.1 面板几何

`compute_layout()` 几何保持不变（面板位置/圆角 24 不变），app 绘制与烘焙共用机制不变。

### 3.2 三套材质参数（bake_glass 按 theme 分支）

统一先 `_fit` 壁纸到窗口尺寸，然后：

- **midnight**：
  - 全图 `brightness × 0.5`（`ImageEnhance.Brightness`）；
  - 大半径径向渐晕替代顶底 scrim：边缘压暗至约 α110，中心不动（消除色带）；
  - 面板：暗玻璃 = 模糊(22) 后叠加深色 `rgb(15,17,22)` α≈132，圆角 24；
  - 面板描边：1px `rgba(255,255,255,0.16)` + 顶部 1px 内高光（沿圆角上缘画半透明白线）。
- **paper**：
  - 全图 `GaussianBlur(26)` + 向白色混合 78%；
  - 面板：再叠白色 α≈184 + 1px 灰描边 `rgba(20,24,34,0.07)`（烘焙柔和投影：面板下方偏移 8px、半径 24、α≈26 的黑）；
- **glass**：
  - 壁纸原样；顶部保留窄渐晕（高度 ≈ 标题行上下各 20px，最深 α≈70）保证白标题可读；
  - 面板：模糊(20) + 白色叠加 α≈117（46%）+ 1px 白描边 + 上缘内高光。

### 3.3 bake_dark（加班）

保留现有暗黑烘焙；三主题下加班都用它（`bake_dark` 不随主题变化），仅微调：
模糊 10、压暗 0.58 保持，可再叠 8% 暗红 `rgb(60,0,0)` 强化压榨氛围。

### 3.4 预生成资产

`make_bg.py` CLI 改为按三主题各生成一份固定尺寸回退背景：`assets/bg_midnight.png` /
`assets/bg_paper.png` / `assets/bg_glass.png`（无 Pillow 回退时按当前主题加载对应文件）；
旧的 `assets/bg.png` 删除，由三主题文件取代；`assets/bg_exploit.png` 保留
（exploit 无主题之分，固定尺寸回退继续用它，生成逻辑不变）。

## 4. 文字与绘制（app.py）

### 4.1 字体

- 主数字、统计值、倒计时 → `Consolas`（回退 `Cascadia Mono`）等宽；主数字 bold；
- 标题/标签/状态行 → 保留 `Microsoft YaHei UI`；
- `scale_fonts()`：主数字上限 56 → **72**（348 宽默认约 40px 起步的现有缩放曲线保持，只放宽上限）；
  等宽字体下加 `letter-spacing` 不可用，维持默认字距（Consolas 数字本身紧凑）。

### 4.2 删除描边光晕

- 移除 `_render_main` 中的 `ht()` 8 向描边辅助；全部 `create_text` 单层绘制；
- 可读性由烘焙层保证：midnight/paper 的文字全部落在面板或渐晕区；glass 标题落在顶部窄渐晕上；
- exploit 画布本就单色底，无需描边。

### 4.3 主题文字色 token（每主题一组）

| token | midnight | paper | glass |
|---|---|---|---|
| accent（主数字/状态行/主按钮） | `#7DB8FF` | `#0A84FF` | `#0066D6` |
| 主文字 | `#F5F5F7` | `#1D1D1F` | `#1D1D1F` |
| 标签文字 | `rgba(235,235,245,0.58)` → `#9698A3` | `#6E6E73` | `#515154` |
| 次要/状态弱化 | `#6B6E78` | `#98989D` | `#6E6E73` |

（tk 颜色不支持 rgba，透明度色值换算为对应实色。）

### 4.4 exploit 画布

- 结构不变（标题/金额/单位/结束按钮）；金额色保持 `#FF1744`、标题 `#FF5252`；
- 「结束加班」按钮统一暗红主按钮样式（现状已符合，仅确认 token 化）。

## 5. 弹窗与菜单 token 化

- 新增 `_theme_tokens()`：返回当前主题的 底色/主文字/次要文字/输入框底/描边/主按钮底/主按钮字/次按钮底 等实色 token；
- 设置弹窗、下班询问弹窗全部从 token 取色（midnight 下为深色弹窗：深底白字、输入框深底、
  主按钮冰蓝、错误红 `#FF6B6B` 提升暗底可读）；
- 保存中的输入校验、掩码逻辑、时间选择控件行为全部不变；
- 原生 tk.Menu 配色同样从 token 取。

## 6. 明确不做（YAGNI）

- 不做强调色切换菜单（冰蓝锁定；将来加 = 改常量表）；
- 不做主题实时预览、不引入第三方 UI 库、不改窗口缩放/防抖、
  不动 `money.py` 公式与 72 条自检、不加新 config 字段（`theme` 取值域变化除外）、
  不做浅色/深色跟随系统。

2. `python make_bg.py` → 生成三主题预生成背景；
3. 无 Pillow 回退分支：删除/改名 make_bg.py 后启动，固定尺寸 + 当前主题背景正常；
4. 手动清单：
   - 三主题各切换一次并重启，主题保持；
   - 旧 config（theme=mint）启动自动迁移为 glass；
   - 每个主题下：主窗口文字可读、设置弹窗可读、下班询问弹窗可读；
   - 缩放窗口 → 防抖重烘焙后面板/文字不错位；
   - 进入/退出加班各主题均切暗红压榨画布并正常恢复；
   - 「标记今天休息」在 paper/glass 下菜单仍可用。

## 8. 风险与对策

- tk Menu 在 Windows 上的深色模式由系统渲染部分区域，无法完全控制 → 接受近似，
  以 activebackground/foreground token 尽量统一；
- Consolas 无中文 → 等宽字体仅用于数字/倒计时（纯 ASCII），中文仍走雅黑；
- 渐晕消除色带依赖 Pillow 每像素写入 → 沿用 `_add_scrims` 的 1px 列拉伸法，性能不变。
