# 时间就是金钱 · 实时薪资钟

一款 Windows 桌面小工具（核心功能零第三方依赖；窗口任意缩放的实时毛玻璃烘焙需 Pillow，未安装时自动回退固定尺寸）：设置月薪、上班时间段、休假方式与发薪日后，主界面以超大字号按秒实时跳动「今日已赚」（另显本月已赚 / 距发薪 / 秒薪）；工作日跨过下班时刻会响铃并弹窗询问「今天加班吗？」，确认加班即强制切换暗黑压榨视图，实时累计「老板在你这里压榨了多少金额」。

**三主题玻璃拟态 UI**：壁纸背景 + 按主题烘焙的玻璃面板，主界面为单 Canvas 文字浮层，数字用等宽字体防抖动：
- **暗夜玻璃（默认）**：壁纸压暗 + 径向渐晕 + 暗玻璃面板，冰蓝数字；
- **纯净亮色**：壁纸强模糊白化 + 近实白卡片，天空蓝数字；
- **经典白玻璃**：白玻璃面板 + 顶底窄渐晕，深蓝数字（旧版样式的精修延续）。

窗口默认 348×452（旧版的 2/3），**可任意拖拽缩放**：拖动中背景每 120ms 跟手重烘（1/3 快速管线 ≈ 20ms/次），松手停稳 150ms 后全质量重烘（需 Pillow，未安装时回退固定尺寸）。窗口圆角经 SetWindowRgn 裁剪（Win10/11 均可用；Win11 可日后切换 DWMWA 原生圆角获得抗锯齿边缘）。

设置与操作全部在顶部菜单栏（配色随主题：亮色主题为浅灰底蓝高亮，暗夜玻璃为深底白字）：**设置**（设置…弹窗，内含当月日历多选休假）、**主题**（暗夜玻璃 / 纯净亮色 / 经典白玻璃）、**标记今天**（▸ 调休 / 请假 / 取消标记；两种假期模式都可用，weekend 模式周末本就休息无需标记）。月薪属机密信息，设置弹窗中默认以 • 掩码显示，勾选「显示」才临时可见，留空保存则保持原值。加班暗黑压榨模式使用独立壁纸 assets/wallpaper_exploit.jpg（模糊压暗 + 红字）。

## 环境要求

- Windows 10 / 11
- Python 3.11（自带 tkinter；铃声用标准库 winsound；**无需安装任何第三方依赖**）

## 启动方式

- 双击 `启动.bat`：以 pythonw 启动，无控制台黑窗口残留；
- 或命令行启动：`pythonw app.py`；
- 调试运行（需要看报错信息时）：`python app.py`。

## 更换壁纸 / 重新生成背景

主界面背景图 `assets/bg_midnight.png` / `bg_paper.png` / `bg_glass.png` 已按三主题预生成（无 Pillow 时按当前主题加载对应文件），运行时无需任何第三方库；只有想换壁纸时才需要 Pillow：

```bash
pip install pillow
python make_bg.py   # 按默认窗口尺寸重生成三主题背景 + 加班背景，面板坐标自动取自 app.py 布局常量
```

修改 app.py 内 `compute_layout()` 的面板几何后，也需重跑 `python make_bg.py`。

## 配置说明（config.json，与 app.py 同目录）

程序在该目录读写 `config.json`（不存在时以默认值进表单，待保存后才落盘）：

| 字段 | 含义 | 取值 |
|---|---|---|
| `monthly_salary` | 月薪（元/月，机密） | 大于 0 的数字；界面中始终掩码 |
| `work_start` / `work_end` | 每天上班开始 / 结束时间 | HH:MM（两位），由时间选择控件选取；开始早于结束，同一天内，不支持跨日 |
| `holiday_mode` | 休假方式 | `weekend`（默认，固定周末公休）/ `free`（自由假期，周末照常上班）；两种模式下均可用设置日历或菜单「标记今天」按日标记休假 |
| `leaves` | 当月休假标记（调休/请假） | `{"2026-09-08": "调休"}`；两种模式通用，由设置日历多选或菜单「标记今天」维护；仅保留当月（跨月自动清）；旧 `free_holidays` 读取时自动迁移为调休 |
| `payday` | 每月发薪日 | 1–31；大于当月天数时按月末算（如 31 → 2 月取 28/29 日） |
| `theme` | 外观主题 | midnight / paper / glass 三选一（旧值 mint/amber/sky 读取时自动迁移为 glass），决定玻璃材质与数字/状态行强调色 |
| `last_asked_date` | 内部字段：已询问过加班的日期 | 程序自动维护，用于当日跨重启不重复询问 |

## 核心公式

- **应出勤天数 D** = 基准工作日 − 当月调休天数；基准工作日：weekend 模式 = 当月天数 − 当月周末数，free 模式 = 当月天数。请假不进 D（扣钱语义）；
- **秒薪** = 月薪 ÷ (D × 每日工作秒数)；调休/请假当天不计薪；调休使 D 减小 → 秒薪按整月重算上调，月薪总额不变；
- **日薪** = 月薪 ÷ D（= 秒薪 × 每日工作秒数）；
- **今日已赚** = 秒薪 × 今日已计薪秒数——仅工作日计薪（weekend 模式 = 周一至五，free 模式 = 全部日期，均排除 leaves 标记的调休/请假）：上班前为 0，班内按秒递增，下班后封顶为一整日（A5）；
- **本月已赚** = 秒薪 × 本月累计计薪秒数——本月 1 日至昨天按工作日各计整日，今天按「今日已赚」口径截断，休假/休息日计 0（weekend 模式 = 周末与 leaves 标记日；free 模式 = leaves 标记日）（A6）；
- **请假损失** = 日薪 × 当月请假天数（月底实收 = 月薪 − 损失）；今天请假时倒计时下方显示「请假中 · 今天没了 {日薪} 元」，今天调休显示「调休中 · 今日不计薪，秒薪已上调」；
- **压榨金额**（加班期间）= 秒薪 × 加班累计秒数——起点取「当日下班时刻」与「加班激活时刻」的较晚者，跨 0 点持续累计不重置（A8）。

## 主题（3 + 1）

| 主题 | 说明 |
|---|---|
| midnight 暗夜玻璃 | 默认；壁纸压暗 + 暗玻璃面板，冰蓝数字 #7DB8FF |
| paper 纯净亮色 | 壁纸强白化 + 近实白卡片，天空蓝数字 #0A84FF |
| glass 经典白玻璃 | 白玻璃面板 + 深蓝数字 #0066D6；旧 mint/amber/sky 配置自动迁移到本主题 |
| exploit 暗黑压榨 | 仅加班期间强制生效（红字黑底画布），与主题选择无关，点「结束加班」后自动恢复 |

## 已知限制（范围外设计，非缺陷）

- 无加班费 1.5x / 2x 系数：压榨金额按基础秒薪 1:1 累计；
- 休息日不响铃、不询问、无休息日加班入口；不识别法定节假日与官方调休安排（休假完全由用户在日历按日标记，日历仅当月，跨月自动清）；
- 无午休扣减、无一天多段排班、不支持通宵跨日班次；
- 无历史统计 / 图表 / 导入导出 / 多配置档案；
- 不提供打包 exe、开机自启、系统托盘、多语言；仅支持 Windows。

## 自检

命令行运行 `python money.py` 可执行内嵌 87 条断言自检（含调休/请假双类型与自由假期模式），正常输出 `87 asserts OK` 且退出码为 0。
