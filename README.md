# 时间就是金钱 · 实时薪资钟

一款 Windows 桌面小工具（**核心功能零第三方依赖**，纯标准库 tkinter）：设置月薪、上班时间段、休假方式与发薪日后，主界面以超大字号按秒实时跳动「今日已赚」（另显本月已赚 / 距发薪 / 每秒进账），并用一条**今日进度条**把上班时间的流逝可视化；工作日跨过下班时刻会响铃并弹窗询问「今天加班吗？」，确认加班即切换**红色警报压榨视图**，实时累计「老板压榨金额」。

**方向A 极简数显 UI**：无壁纸、无贴图，深色（或浅色）纯色渐变底上全部 Canvas 矢量绘制——

- 自绘标题栏：应用名 + `◐` 主题切换 + `⚙` 设置（右键菜单含 主题 / 标记今天 / 设置…）；
- 主数字整数/小数分字号等宽字体，每秒跳动不抖宽；
- 今日进度条（09:00 → 18:00）+ 完成百分比刻度；
- 底部三栏统计：本月已赚 / 距发薪 / 秒薪，细分隔线分区；
- 双主题：**dark 暗夜极简**（默认）/ **light 清晨亮色**，加班期统一切换红色警报调色板。

窗口默认 348×452，**可任意拖拽缩放**：布局全部按比例即时重排（渐变底逐行重画，无需重烘焙贴图）。窗口圆角经 SetWindowRgn 裁剪（Win10/11 均可用）。

操作入口：`⚙` 打开设置弹窗；`◐` 在深色/浅色间切换；**右键窗口**弹出菜单（主题二选一、标记今天 ▸ 调休/请假/取消标记、设置…）。月薪属机密信息，设置弹窗中默认以 • 掩码显示，勾选「显示」才临时可见，留空保存则保持原值。加班红色压榨模式：主数字变「老板压榨金额」，进度条变加班时长条（4 小时满格，中央显示每秒损失），点「结束加班」恢复。

## 环境要求

- Windows 10 / 11
- Python 3.11（自带 tkinter；铃声用标准库 winsound；**无需安装任何第三方依赖**）

## 启动方式

- 双击 `启动.bat`：以 pythonw 启动，无控制台黑窗口残留；
- 或命令行启动：`pythonw app.py`；
- 调试运行（需要看报错信息时）：`python app.py`。

## 配置说明（config.json，与 app.py 同目录）

程序在该目录读写 `config.json`（不存在时以默认值进表单，待保存后才落盘）：

| 字段 | 含义 | 取值 |
|---|---|---|
| `monthly_salary` | 月薪（元/月，机密） | 大于 0 的数字；界面中始终掩码 |
| `work_start` / `work_end` | 每天上班开始 / 结束时间 | HH:MM（两位），由时间选择控件选取；开始早于结束，同一天内，不支持跨日 |
| `holiday_mode` | 休假方式 | `weekend`（默认，固定周末公休）/ `free`（自由假期，周末照常上班）；两种模式下均可用设置日历或右键菜单「标记今天」按日标记休假 |
| `leaves` | 当月休假标记（调休/请假），分模式独立 | `{"weekend": {"2026-09-08": "调休"}, "free": {"2026-09-12": "请假"}}`；设置日历与右键菜单只编辑当前模式的组，互不影响；各组仅保留当月（跨月自动清）；旧 `free_holidays` 读取时自动迁移进 free 组（调休） |
| `payday` | 每月发薪日 | 1–31；大于当月天数时按月末算（如 31 → 2 月取 28/29 日） |
| `theme` | 外观主题 | `dark`（默认，暗夜极简）/ `light`（清晨亮色）；旧值 midnight→dark，paper/glass/mint/amber/sky→light 自动迁移 |
| `last_asked_date` | 内部字段：已询问过加班的日期 | 程序自动维护，用于当日跨重启不重复询问 |

## 核心公式

- **应出勤天数 D** = 基准工作日 − 当月调休天数；基准工作日：weekend 模式 = 周一至五 + 法定补班周末 − 法定节休（已内置 2026 年官方安排），free 模式 = 当月天数。请假不进 D（扣钱语义）；
- **秒薪** = 月薪 ÷ (D × 每日工作秒数)；调休/请假当天不计薪；调休使 D 减小 → 秒薪按整月重算上调，月薪总额不变；
- **日薪** = 月薪 ÷ D（= 秒薪 × 每日工作秒数）；
- **今日已赚** = 秒薪 × 今日已计薪秒数——仅工作日计薪（weekend 模式 = 周一至五 + 法定补班周末 − 法定节休，free 模式 = 全部日期，均排除 leaves 标记的调休/请假）：上班前为 0，班内按秒递增，下班后封顶为一整日（A5）；
- **本月已赚** = 秒薪 × 本月累计计薪秒数——本月 1 日至昨天按工作日各计整日，今天按「今日已赚」口径截断，休假/休息日计 0（weekend 模式 = 周末、法定节休与 leaves 标记日；free 模式 = leaves 标记日）（A6）；
- **请假损失** = 日薪 × 当月请假天数（月底实收 = 月薪 − 损失）；今天请假时副文案显示「今天没了 {日薪} 元」，今天调休显示「今日不计薪，秒薪已上调」；
- **压榨金额**（加班期间）= 秒薪 × 加班累计秒数——起点取「当日下班时刻」与「加班激活时刻」的较晚者，跨 0 点持续累计不重置（A8）；本月已赚在加班期间继续累计（含压榨部分）。

## 主题（2 + 1）

| 主题 | 说明 |
|---|---|
| dark 暗夜极简 | 默认；#0E0F13 → #171A21 渐变底，冰蓝数字 #7DB8FF |
| light 清晨亮色 | #F5F5F7 → #FFFFFF 渐变底，系统蓝数字 #0A84FF |
| 红色警报（压榨） | 仅加班期间生效：暗红渐变底 + #FF5252 红字，与主题选择无关，点「结束加班」后自动恢复 |

## 已知限制（范围外设计，非缺陷）

- 无加班费 1.5x / 2x 系数：压榨金额按基础秒薪 1:1 累计；
- 休息日（周末、法定节休、leaves 标记日）不响铃、不询问、无休息日加班入口；法定节假日已内置 2026 年官方安排（含调休补班周末，静态嵌入 money.py），其他年份只认周末，2027 年待官方公布后补录；日历仅当月，跨月自动清；
- 无午休扣减、无一天多段排班、不支持通宵跨日班次；
- 无历史统计 / 图表 / 导入导出 / 多配置档案；
- 不提供打包 exe、开机自启、系统托盘、多语言；仅支持 Windows。

## 自检

- 命令行运行 `python money.py` 可执行内嵌 103 条断言自检（含 2026 法定节假日表、调休/请假双类型与自由假期模式），正常输出 `103 asserts OK` 且退出码为 0；
- 命令行运行 `python test_redesign.py` 可执行 UI 层自检（主题迁移 / tag 契约 / 压榨流程），正常输出 `ALL OK`。
